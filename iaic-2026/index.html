Ctrl-World 로봇팔 월드모델 파인튜닝

2026.07 – 08 · 개인 프로젝트

대회 기준 GPU(RTX PRO 6000 96GB)보다 훨씬 작은 24GB, 이어서 48GB GPU로 로봇팔 영상 예측 모델(Ctrl-World)을 세 차례 다시 학습시키며, 실제 리더보드 점수를 0.4578에서 0.2446까지 끌어올렸습니다. 서버가 제약될수록 병목을 코드 레벨에서 정확히 찾아내는 게 관건이었습니다.

  • 학습 전처리와 채점 파이프라인의 리사이즈 방식(비율 무시 stretch vs 레터박스)이 어긋나 있던 걸 발견 — 이 한 줄 차이가 1라운드 전체 결과를 정지 화면보다 못하게 만들고 있었음.
  • guidance_scale > 1.0이면 매 스텝 UNet을 2배 호출한다는 걸 코드에서 직접 찾아내 1시간 추론 예산 문제를 해결.
  • 자체 채점 실험 결과가 규정상 쓸 수 없는 것이었음을 제출 전에 스스로 발견·폐기하고, 동일 실수가 코드 수준에서 재발하지 않도록 lock 가드를 구현.

Latent Optical-Flow 기반 프레임 예측 실험

2026.08 · 개인 프로젝트

로봇팔 영상 생성 모델의 "예측이 흐려지는" 문제를, 내부 지표가 아니라 실제 프레임의 픽셀 변화량을 직접 측정해 원인을 규명했습니다. latent 공간에서 delta 대신 optical flow + residual을 예측하도록 아키텍처를 바꿔 검증했습니다.

  • "픽셀이 같은 자리에서 값만 바뀐다"는 delta 방식의 암묵적 가정이 팔이 실제로 이동하는 태스크와 안 맞는다는 걸 짚고, warp+residual 구조로 재설계.
  • 내부 검증 지표가 가장 좋던 체크포인트가 실제 점수는 가장 나쁘고, 가장 나쁘던 쪽이 실제로는 가장 좋았던 역전을 4개 체크포인트로 확인 — "더 학습한다고 실제 성능이 보장되지 않는다"는 근거.
  • optimizer를 재개할 때 학습률이 조용히 이전 값으로 되돌아가는 버그, 검증셋이 매번 무작위로 바뀌어 체크포인트 비교가 무의미했던 문제를 코드에서 직접 찾아 수정.
