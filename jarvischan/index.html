Jarvischan — 영화 스타일 음성 비서

2026.09 · 개인 프로젝트

말로 묻고 답하는 음성 비서를 Vercel에 무료로 배포하고, 실사용 중 나온 문제들 (마이크 경합, 무음 판정, TTS 컷오프, 배포 파이프라인, 모바일 전용 재발, 아이폰 무음 대답)을 Claude Code와 함께 진단·수정하고, 서버가 닿을 수 없는 사용자 컴퓨터를 직접 제어하는 로컬 에이전트까지 새로 설계·구현한 프로젝트입니다.

로컬 에이전트 명령(앱 제어~볼륨)
  • 웨이크워드 인식기와 Whisper 녹음이 마이크를 두고 벌이던 비동기 경합을 진단 — "성공한 것처럼 보이지만 실제로는 죽어있는" 상태의 원인을 찾아 수정.
  • 진폭(음량) 기준 무음 판정을 세 번 다듬다가, 한계를 인정하고 브라우저 자체의 음성종료 감지(onspeechend) API로 접근을 전환 — 파라미터 튜닝과 아키텍처 전환의 갈림길을 실제로 겪은 사례. 이후 실기기(아이패드)에서 iOS엔 그 API 자체가 없다는 걸 발견하고, AGC·기준 상한·재보정 속도 세 겹을 더 수정.
  • Vercel 배포가 원인 불명으로 계속 멈추던 문제를, 후보를 하나씩 제거해나가며 결국 Vercel이 보낸 이메일에서 로컬 git 커밋 이메일 불일치라는 진짜 원인을 특정.
  • Vercel 서버가 사용자 컴퓨터에 닿을 수 없다는 아키텍처 한계에서 출발해, 노트북에서 직접 실행하는 WebSocket 에이전트를 새로 설계 — 화이트리스트·페어링 토큰으로 범위를 좁히고, 강제종료로 저장 안 한 작업이 날아갈 수 있던 위험을 스스로 검토해 사전에 수정.
  • 아이폰에서만 대답 소리가 안 나던 문제를, 추측성 수정 세 번이 증상만 바꾸자 방향을 바꿔 "텍스트로 먼저 vs 음성으로 먼저" 대조 실험으로 원인(음성 합성이 마이크보다 먼저 한 번 재생돼야 함)을 특정하고 첫 탭의 짧은 확인 음성으로 해결.
