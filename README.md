# kheechan04.github.io

김희찬 개인 포트폴리오 사이트 소스입니다. 실제 페이지: **https://kheechan04.github.io**

## 구조

```
.
├── index.html          ← 프로젝트 목차(허브) 페이지
└── iaic-2026/           2026 인하 인공지능 챌린지 — 로봇팔 월드모델
    ├── index.html      ← 요약 포트폴리오 (프로젝트 카드형)
    └── full.html       ← 상세 기록 (전체 시행착오·인프라 사고·코드 발췌 포함)
```

## 새 프로젝트 추가하는 법

1. `프로젝트슬러그/` 폴더를 새로 만들고 그 안에 `index.html`(요약)을 배치. 상세 기록이 있으면 같은 폴더에 `full.html`로 추가.
2. 루트 `index.html`의 "프로젝트" 목록(`.proj-list`)에 카드 블록 하나를 복사해서 새 프로젝트로 채워 추가.

폴더 이름과 루트 `index.html`의 링크(`href="/프로젝트슬러그/"`)만 맞추면 나머지 구조는 그대로 재사용됩니다.
