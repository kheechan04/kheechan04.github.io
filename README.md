# kheechan04.github.io

김희찬 개인 포트폴리오 사이트 소스예요. 실제 페이지: **https://kheechan04.github.io**

## 구조

```
.
├── index.html          ← 프로젝트 목차(허브) 페이지
├── iaic-2026/          2026 인하 인공지능 챌린지 — 로봇팔 월드모델
├── jarvischan/         Jarvischan — 영화 스타일 음성 비서
├── shadow-mitts/       Shadow Mitts — 웹캠 복싱 미트 게임
└── sonmat-real-casting/ 손맛: 리얼 캐스팅 — 웹캠 낚시 게임
```

프로젝트 폴더마다 두 쪽이 있어요.

- `index.html` — 요약 포트폴리오 (프로젝트 카드형)
- `full.html` — 상세 기록 (전체 시행착오·원인 분석·코드 발췌)

## 새 프로젝트 추가하는 법

1. `프로젝트슬러그/` 폴더를 새로 만들고 그 안에 `index.html`(요약)을 둬요. 상세 기록이 있으면 같은 폴더에 `full.html`로 추가해요.
2. 루트 `index.html`의 "프로젝트" 목록(`.proj-list`)에서 카드 블록(`.proj-card`) 하나를 복사해 새 프로젝트로 채워요.

폴더 이름과 루트 `index.html`의 링크(`href="/프로젝트슬러그/"`)만 맞추면 나머지 구조는 그대로 재사용돼요.

## 쓰는 규칙

- 수치는 실제로 잰 것만 써요. 측정하지 않은 비교는 "검토"라고만 써요.
- 문체: 허브와 요약 페이지 본문은 "\~습니다", 카드의 항목은 짧은 명사형, 상세 기록은 "\~한다".
- 저장소 링크 옆에는 공개 여부를 적어요: (공개), (공개 · MIT 라이선스), (비공개).
